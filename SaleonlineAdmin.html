🔄 Update Store — Sync with Source

Press the button to match every product in your store with the source app: prices, stock and details are checked, and anything changed there is updated here too — so you never face a loss or a customer complaint.

✏️ Manual Prices (Protected)

These items' prices were changed manually by you. Update Store will never change their price (only stock and other details). Press Update with Source on any item to restore its automatic source price — it will move back to the main Store Items list.

🔄 Import / Export Data

Products ka data download karke manually edit karein (price, details, ya naye products add karein), phir wohi file upload karke import karein.
Upsert only: file mein mojood products update ya add honge — jo products file mein NA hon, woh delete NAHI honge, waisay hi rahenge.
Price: file mein jo price hogi wohi effective price ban jayegi. Manual price wali items ki manual price mehfooz rehti hai, aur agar price badli to woh manual (protected) ho jayegi.
Import server par apply hoti hai (usually aik ghante ke andar) — status neeche nazar aayega.
